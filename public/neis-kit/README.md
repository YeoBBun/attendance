# 출결 앱 → 나이스 자동 입력 연결

출결 앱에서 매일 입력한 출결을 [neis-automation-kit](https://github.com/workcalmkite-hue/neis-automation-kit)
(방배중 안정연 선생님 제작)으로 나이스 「일일출결관리(담임용)」에 넣는 방법입니다.

키트는 원래 **구글 캘린더**에서 출결을 읽습니다. 여기 있는 `app_to_neis.py` 가 그 부분만
**출결 앱에서 내보낸 파일**로 바꿔 끼웁니다. 키트 코드는 고치지 않으므로 키트를 업데이트해도 그대로 씁니다.

> ⚠️ 키트는 브라우저를 자동으로 조작합니다. 학교·교육청 허락을 받고 쓰고,
> 넣은 뒤에는 **나이스 화면에서 꼭 눈으로 확인**하세요.

## 처음 한 번 (학교 PC)

1. 키트의 `시작하기.md` 대로 키트를 설치하고 설정 마법사를 돌립니다.
   - 마법사 「6. 학생 출결 자동화 (구글 캘린더)」에서는 **n** 을 눌러 건너뛰어도 됩니다.
     (출결은 구글 캘린더 대신 앱 파일로 넣으므로 구글 연동이 필요 없습니다.)
2. 키트 폴더를 연 클로드 앱에 이렇게 말합니다:

   ```
   https://yeobbun.github.io/attendance/neis-kit/app_to_neis.py 를 이 폴더에,
   https://yeobbun.github.io/attendance/neis-kit/SKILL.md 를 .claude/skills/앱출결/SKILL.md 로 받아줘.
   받은 파일을 읽어보고 무슨 일을 하는지 한 줄로 설명해줘.
   ```

   받은 뒤에는 클로드 앱을 껐다 켜야 `/앱출결` 이 보입니다.

## 넣을 때마다

1. **휴대폰 앱**: 「출결 기록」 탭 → **나이스 파일** → 기간 확인 → **파일 저장**
   - 결과, 교시가 없는 지각·조퇴는 자동으로 못 넣습니다. 화면에 따로 표시되니 나이스에서 직접 넣으세요.
2. 파일(`attendance_neis_날짜-날짜.json`)을 **학교 PC의 다운로드 폴더**로 옮깁니다.
   (예: 카카오톡 「나와의 채팅」으로 보내고 PC 카카오톡에서 저장)
3. 키트 폴더의 클로드 앱에 **"앱 출결 나이스에 넣어줘"** (또는 `/앱출결`)
   - 먼저 목록만 보여 주고, 확인하면 넣습니다.
4. 나이스 화면에서 확인한 뒤 마감합니다. **파일은 지웁니다** (학생 이름·출결이 들어 있음).

## 직접 실행할 때

```powershell
.\.venv\Scripts\python.exe -X utf8 app_to_neis.py --dry-run   # 목록만
.\.venv\Scripts\python.exe -X utf8 app_to_neis.py             # 넣기
.\.venv\Scripts\python.exe -X utf8 app_to_neis.py --future    # 미래 날짜도 넣기
```

## 파일 형식

```json
{
  "format": "attendance-app/neis-v1",
  "from": "2026-10-01", "to": "2026-10-15",
  "records": [
    { "date": "2026-10-14", "number": 7, "name": "박지우", "att_type": "미인정지각", "note": "~2교시" }
  ],
  "skipped": [ { "date": "...", "number": 3, "name": "...", "label": "질병결과", "reason": "..." } ]
}
```

- 날짜마다 한 줄 (결석 기간은 수업일마다 풀어서, 주말·공휴일·재량휴업일 제외)
- `att_type` 은 키트의 분류 이름 (질병결석, 출석인정조퇴 …)
- `note` 는 키트의 교시 표기: 지각 `~N교시`(조회만이면 `조회`), 조퇴 `N교시~`, 결석은 빈칸
