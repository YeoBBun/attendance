# 출결 앱 → 나이스 자동 입력

나이스 입력은 **출결 앱 연동판 키트** 저장소에서 합니다:
https://github.com/YeoBBun/neis-automation-kit

(방배중 안정연 선생님의 [neis-automation-kit](https://github.com/workcalmkite-hue/neis-automation-kit) 포크)

1. 학교 PC에 키트를 설치합니다 (README 의 설치 문장 그대로, 설정 마법사 6번 구글 캘린더는 n).
2. 크롬에서 출결 앱 → 「출결 기록 → 나이스 파일」 → 파일 저장 (다운로드 폴더).
3. 키트 폴더의 클로드 앱에 "앱 출결 나이스에 넣어줘" (`/앱출결`).
4. 나이스 화면에서 확인하고 마감한 뒤, 파일은 지웁니다.
